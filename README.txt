ENTRE PÁGINAS — SITE DE LIVROS DE ROMANCE

Arquivos:
- index.html: estrutura da página
- style.css: cores, layout e responsividade
- script.js: catálogo, busca, filtros e sacola demonstrativa

Como abrir no VS Code:
1. Extraia o arquivo ZIP.
2. Abra a pasta "livros_romance" no Visual Studio Code.
3. Abra o arquivo index.html no navegador. Se tiver a extensão Live Server, clique com o botão direito em index.html e selecione "Open with Live Server".

Observação:
Este projeto é uma vitrine demonstrativa. A sacola funciona apenas no navegador; não há pagamento nem compra real.
